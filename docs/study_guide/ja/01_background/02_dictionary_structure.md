## 辞書を読むとき何が起きているか

辞書で「猫（cat）」を調べると「毛皮のある四本足の動物」と書いてある。
「動物」を調べると「生命のある有機体」と書いてある。
「生命」を調べると…どこかで定義の連鎖は閉じる。

この連鎖を **有向グラフ** として捉えたのが辞書グラフ分析の出発点である。

---

## 辺の向きの規約（最重要）

```
「cat」の定義に「animal」が現れる
    → add_edge("animal", "cat")   # animal が cat を定義する
    → エッジの向き：animal ──→ cat
```

> **なぜ animal → cat か**：「animal は cat を定義するために**使われる**」という方向性。
> 逆（cat → animal）ではないことに注意。

Python での実装：

```python
# "cat の定義に animal が現れる" 場合
G.add_edge("animal", "cat")   # u=animal（定義語）, v=cat（被定義語）
```

## カーネルの直観

出次数が 0 のノードとは「他のどの語の定義にも使われない語」である。
そのような語を除去してもカーネルは変わらない——なぜなら、
その語は他の語を定義する役割を持っていないからだ。

除去を繰り返して**最後に残る語**が **カーネル**。
カーネルは「お互いだけで閉じた定義語彙集合」である。

```
語彙: {cat, animal, fur, big, run, jump}
定義:
  cat → animal, fur（animal と fur が cat の定義に登場）
  animal → big（big が animal の定義に登場）
  fur → (なし)
  big → (なし)
  run → jump
  jump → run

ステップ1: 出次数 0 は fur, big → 除去
ステップ2: cat は出次数 0（fur と animal は消えた）、
           animal は出次数 0（big は消えた） → 除去
ステップ3: run と jump は互いを指す → 残る

カーネル = {run, jump}
```

---

## サニティチェック：3 ノードチェーン

```
add_edge("B", "A")   # A の定義に B が現れる
add_edge("C", "B")   # B の定義に C が現れる

A の出次数 = 0  → ステップ1で除去
B の出次数 = 1（A を指す）→ A 除去後 出次数 0 → ステップ2で除去
C の出次数 = 1（B を指す）→ B 除去後 出次数 0 → ステップ3で除去

Kernel = {} （空！）
```

閉路がないとカーネルは空になる。人間辞書では約 10% がカーネルに残る。

---

## コアの直観

カーネルを求めたあと、カーネル内部のグラフを縮約 DAG に変換する。
その **Source SCC**（入次数 = 0 の SCC）の和集合が**コア**。

コアは「他の概念を定義するために使われるが、自分自身は外から参照されない概念の循環クラスター」。
意味論的には「語の根」に相当する。

> **注意**：コアは「最大 SCC」ではない。
> Source SCC が複数あれば、最大 SCC がその一つでないこともある。

## 人間辞書の典型的な値（Vincent-Lamarre et al., 2016）

| 指標 | Longman | Cambridge | Webster | WordNet |
|---|---|---|---|---|
| カーネル率 | ~10% | ~10% | ~8% | ~15% |
| Core/Kernel 比 | ~75% | ~70% | ~65% | ~90% |
| MinSet 率 | ~1% | ~1% | ~1% | ~1% |
