# スケーリング則と知識容量

## Chinchilla スケーリング則（Hoffmann et al., 2022）

> Hoffmann, J., et al. (2022). Training compute-optimal large language models. *NeurIPS 2022*.

**発見**：モデルサイズ N とトークン数 D には最適な比率がある。

```
最適：N ≈ D / 20  （データ量はパラメータ数の 20 倍が目安）
```

以前は「大きいモデル = 良いモデル」と思われていたが、
Chinchilla は「同じ計算量なら小さくて多くのデータで学習した方が良い」と示した。

---

## 知識容量の推定（arXiv:2404.05405）

パラメータ数と「記憶できる事実知識の量」の関係を推定した研究。

**結論**：1 パラメータ ≈ 2 ビットの事実知識

| モデル | パラメータ | 推定知識容量 |
|---|---|---|
| Qwen3.5-0.8B | 8億 | ~200 MB 相当 |
| Qwen3.5-27B | 270億 | ~6.75 GB 相当 |

**本研究との接続**：知識容量がスケールと増加するなら、
定義の「語彙的効率」（小さいカーネルで多くを表現できる）もスケールと変化するはず。

---

## 知識の創発（emergence）

大きなモデルでは、ある能力が突然「出現」することが報告されている。

```
小さいモデル → 一定のタスクで偶然レベル
        ↓ パラメータ数を増やす
大きいモデル → 急に人間レベルに到達（創発）
```

本研究の mset/k 比（r = +0.982 でスケールと強相関）は、
この「段階的変化か連続変化か」という問いに答える一つの証拠になる。

---

## 本研究の位置付け

既存のスケーリング則は「**損失（perplexity）**」や「**ベンチマークスコア**」を指標にする。

本研究はそれに加えて：
- 「定義ネットワークの位相構造」という**新しい指標軸**を提案
- 損失に依らない、**アーキテクチャ非依存の計量**

```
既存のスケーリング則:   パラメータ数 → 損失
本研究の追加貢献:       パラメータ数 → グラフ位相構造（カーネル・mset/k）
```
