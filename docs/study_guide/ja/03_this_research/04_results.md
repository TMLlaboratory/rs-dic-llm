# 実験結果の読み方

**所要時間**：60分

---

## 結果の全体像

```
Qwen3.5 ファミリー（同一アーキテクチャ、スケールが異なる）
          ↓
カーネル率: 17.9% → 11.1% → 10.8% → 10.1% → 8.6%  （単調減少 r=−0.862）
mset/k比:  14.4% → 16.7% → 17.1% → 18.1% → 20.3%  （単調増加 r=+0.982）
```

```
Gemma-4 ファミリー（異なるアーキテクチャ）
- 指示追従率 99.9%（Qwen3.5 は 7〜24%）
- カーネル率: 7.3%（4B）, 8.1%（31B）← 同サイズ Qwen3.5 より低い
- mset/k: 23.3%（4B）, 16.2%（31B）← 4B は特に高い
```

---

## ピアソン相関係数の読み方

```
r = +1.0: 完全な正の相関（x が増えると y も増える）
r =  0.0: 無相関
r = −1.0: 完全な負の相関（x が増えると y は減る）
```

**本研究の主要な r 値**：

| 指標 vs log2(params) | Qwen3.5内 | 7モデル全体 |
|---|---|---|
| kernel_ratio | −0.862 | −0.757 |
| mset/k | **+0.982** | +0.318 |
| circ | −0.675 | − |

mset/k の r=+0.982 は非常に強い相関——データ点 5 個でこれほど綺麗に並ぶのは稀。

## WordNet との比較

WordNet のカーネル率は 15.5%——Qwen3.5-0.8B（17.9%）に近く、
Qwen3.5-27B（8.6%）よりはるかに高い。

**解釈**：
- WordNet は同義語リストで「cycling」しやすい構造
- 大規模 LLM は人間辞書の 10% に近づいている
- 但し MinSet の比較（LLMの方が高い）は「核の循環が密」を示す

## 量子化結果の読み方

```
Qwen3.5-27B の量子化比較:
bf16 → 8bit → 6bit → 4bit

kernel%:  8.6 → 9.4 → 8.2 → 8.7
                ↑
          8-bit が最も bf16 から乖離（+0.8pp）
          4-bit は bf16 に最も近い（+0.1pp）
```

**なぜ 4-bit が安定か**：MLX の 4-bit 量子化は group-wise であり、
8-bit よりも出力分布の乱れが少ない可能性がある（実装詳細は未調査）。

**実用的意味**：4-bit 量子化で推論コストを大幅削減しても、
グラフ指標は bf16 とほぼ同等 → **低コスト推論で十分**。
